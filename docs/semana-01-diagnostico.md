# Semana 01 — Diagnóstico (19 a 25/10/2026)

Este diagnóstico serve para descobrir seu ponto de partida. Não tem objetivo de te julgar.
Tente sozinho; registre dúvidas e bloqueios antes de buscar ajuda.

## A. Fundamentos (20 min)

1. Qual a diferença entre array e `ArrayList`? Dê um cenário para cada.
2. Qual o custo esperado de busca em `HashMap`? Quando ele pode piorar?
3. Quando `==` e `.equals()` produzem resultados diferentes?
4. Explique O(n²) com um exemplo e compare com O(n).
5. Dê um exemplo de algoritmo que usa O(n) de memória adicional.

## B. Código (45 min)

- `FirstUniqueCharacter.firstUniqueCodePoint(String)`: retorne o primeiro ponto de código Unicode que ocorre uma vez; se não existir, retorne `OptionalInt.empty()`. Comece por entradas ASCII; Unicode é bônus.
- `TwoSum.findIndices(int[], int)`: retorne dois índices `i < j` cujo par soma o alvo; se nenhum existir, retorne array vazio. Primeiro tente força bruta; depois procure uma melhoria.

Não veja soluções prontas antes da sua tentativa. Se travar, escreva o que tentou.

- Pelo menos 3 casos-limite e como testá-los.
